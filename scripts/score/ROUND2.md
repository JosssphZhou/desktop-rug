# 第二轮爬坡

## 翻回动作的分叉

固定 f0740 的平铺初态，重放 f0744 到 f0958。原版松手阻尼为 0.8 时，f0920 抓到网格点 561，结束时翻面点为 0；阻尼为 0.5 时抓到点 771，结束时约有 90 个翻面点。

做反事实对照，只强制第二次抓取的材料点，其他输入和参数不动：

| 阻尼 | 固定抓点 | f0958 之后翻面点 |
|---|---:|---:|
| 0.8 | 561 | 0 |
| 0.8 | 771 | 98 |
| 0.5 | 561 | 0 |
| 0.5 | 771 | 98 |

因此主因不是分数随机抖动：前一段的形状和停稳状态改变后，`beginGrab` 的“距离减去高度权重”选中了不同材料点，离散抓点把一个小形状差异变成两个展开结果。固定抓点后两种阻尼的结局一致，排除了阻尼直接主导最后结局的解释。固定抓点仅用于诊断，相关代码已移除，不把视频中的网格编号写进产品。

输入光标轨迹本身约有 10 像素人工读取误差。因此扫描期间按主控给出的临时宽门槛记录结果，同时单独保留这一段的分数；不能把较差展开称为同样好。第一、第二、第四段最多下降 0.03，翻回段最多下降 0.10。每个保留版本既对照上个保留版本，也对照第二轮起点，防止逐步累积退步。

## 扫描与保留

运行 `sweep.py` 时，用包含 NumPy 与 OpenCV 的 Python 环境。编译和测试由各自入口排队，不在外层再包一层队列。

```sh
BUILDQ_MIN_FREE_GB=10 RUG_SCORE_PYTHON=你的Python路径 你的Python路径 scripts/score/sweep.py --cycle 1 --params optmatch,crease,foldfric
```

完整参数表在 `sweep.py` 的 `PLAN`。一整轮包含 Option 曲线、折痕约束、翻面贴地摩擦、中间帐篷逻辑及十一项物理参数。每项先扫五个粗值，再围绕最佳合格值扫描相邻细值。只有完整扫描两轮都没有保留改动才结束，不能用几个参数失败代替整轮。

快速扫描仍处理全部 1328 帧，没有隔帧。它将原来的 2×2 面积缩小移到 PNG 编码前，以减少透明截图传输；起点对照总分相差约 0.000008。所有准备保留的候选都再走原始截图分辨率确认，不用快速分数作最终保留依据。

保留顺序：原分辨率总分上升、四段满足门槛、四项原有回归和新增“折叠保持及选中控件仍可用”检查通过，再完整生成 `web/tuning.js` 并提交。失败立即恢复原参数对象。扫描不修改其他源码，不合并或推送。

完全相同的逻辑版本和有效参数可以复用已有逐帧结果，日志明确写“缓存”，不把它记为新重放。数值曲线和参数持续保存；原始截图每次结束都清理，对比看板自查后删除。最终版本单独重新录制完整视频。

## 布料与选中动效的可调逻辑

- `crease`：只降低跨正反面交界的弯曲约束，保留其他区域抗皱刚度。
- `foldfric`：增加翻过去且贴地的片的地面摩擦及静摩擦阈值。
- `tent`：抓中间时抬得更高，降低沿拖动方向的阻力，抑制横向收拢。不加拉回原位的力。
- `optmatch`：在旧动画与依据参考本体轮廓重测的曲线之间粗扫。曲线同时约束宽高、微小过冲、抬起和白点延迟，尺寸补偿透视变化。DOM 控件与录制图共用白点尺寸，动效结束后操作条必须仍可用。

这些逻辑的中性值与第二轮起点完全一致，已经用完整评分入口验证：总分仍为 0.578481。
