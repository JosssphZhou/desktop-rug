# 按参考视频评分

## 运行

在项目根目录运行：

```sh
python3 -m venv .score-cache/venv
.score-cache/venv/bin/pip install -r scripts/score/requirements.txt
BUILDQ_MIN_FREE_GB=10 RUG_SCORE_PYTHON="$PWD/.score-cache/venv/bin/python" scripts/score.sh --label baseline
```

`score.sh` 在缺少临时宿主时，通过 `buildq` 编译到 `.score-cache/DesktopRug`。逐帧重放经过 `testq`。可以用 `RUG_BIN` 指定已有宿主，用 `RUG_SCORE_PYTHON` 指定已有 Python 环境，不覆盖 `build/`。上面的 10 GB 门槛是主控对本任务的单独授权，不写进脚本默认值。脚本在内置盘低于 11 GB 时终止本轮，并清理临时截图。缓存、临时文件和宿主测试用的用户目录都在外置工作树 `.score-cache/`。

只预处理参考视频、不启动应用：

```sh
RUG_SCORE_PYTHON=你的Python路径 scripts/score.sh --prepare-reference
```

默认参考视频路径在 `score.py` 中。`--reference` 可以指定同一文件的其他路径，SHA256 不匹配时拒绝使用固定镜头标定。

临时窗口在桌面下面。重放使用应用真实的抓取、物理、Option 和渲染函数，不移动系统鼠标，也不读取桌面文件。测试要求主屏视口为 2560×1440 点，与上一轮一致。其他视口明确报错，不输出错误尺度的分数。位置由 `--rug` 指定，不写回地毯位置。程序只退出本次启动的实例。

结果保存在每次新建的 `.score-cache/日期-标签-随机值/`：

- `score.json`：总分、四段 IoU、节奏、停稳时间、Option 测量值。
- `provenance.json`：提交、物理文件、宿主、视频和评分文件的 SHA256。
- `curves.json`：1328 帧的 IoU、轮廓变化曲线和选中动效测量值。
- `comparison.mp4`：加 `--evidence` 后导出的 60 fps 并排对比，不用插帧。
- `keyframes.jpg`：18 个关键时刻。
- `replay.log`：重放完成标记和逐帧物理数据。缺帧或抓空拒绝计分。

透明原图在计分后删除。失败或中断时也清理本轮临时截图，不删除外部素材。关键帧图供每轮自查，查看后删除，仅最终交付保留图片和视频。普通尝试只保留分数、数值曲线、参数及日志。右侧背景来自参考视频的地板拼接，不是真实桌面；不合成桌面文件或图标。原生菜单和真实鼠标手感未被此脚本验证。

## 固定评分公式

所有分量范围为 0 到 1，越大越好。权重在第一轮基线前固定。

```text
总分 = 0.55 × I + 0.20 × T + 0.15 × S + 0.10 × O
```

### 轮廓 I

f0236 到 f1563 每一帧计算 IoU，再取平均，共 1328 帧。另报四段：236..420、430..518、920..957、1414..1478。空间分辨率为 831×540，时间保持 60 fps。

轮廓按红色及深色边框分割，取最大连通区域并填内部花纹孔洞，不使用凸包。人像、菜单栏、Option 按键提示、蓝色标签对应的图标区域先排除。参考与候选用同一可见区域，图标遮住的地方不猜布的形状。前后帧运动量使用两帧可见区域的交集。

固定的逐帧镜头矩阵将参考映射到 f0700 坐标。候选不做逐帧形状配准。f0524、f0740、f1028、f1405 仍按上一轮的固定初态重新摆放，不能随候选改变。

### 时间节奏 T

每帧变化量 `d[f] = |M[f] XOR M[f-1]| / |M[f] UNION M[f-1]|`。两条曲线各做三帧对称均值，不允许平移时间轴或动态时间规整。

每段分数为 `exp(-mean(abs(d参考-d候选)) / max(mean(d参考), 0.002))`。七个动作观察段等权平均：238..420、430..523、527..739、744..919、920..1027、1033..1346、1414..1563。段内包含松手后的停顿。人为对齐帧及其前后各一帧不进入节奏分，但仍进入 IoU。

### 松手停稳 S

松手观察段：294..420、519..523、593..739、783..919、958..1027、1479..1563。

停稳阈值只由参考静止段 f0300..f0420 确定：`max(0.0005, 参考变化量95分位数×2)`。停稳要求连续至少六帧低于阈值，且剩余观察段不再运动。两者都能观察到终点时，分数为 `exp(-abs(候选帧数-参考帧数)/30)`。

如果下一次抓取、重新对齐或视频结束截断了观察，就报告 `censored=true`，不把观察窗结束伪称为停稳。此时该段使用可见运动曲线的节奏分。六段等权平均。

### Option 动效 O

使用 f1030..f1100，等权比较四项：

1. 相对各自 f1030 的宽高曲线。误差尺度为 2.5%。
2. 宽高峰值、峰值帧数和达到稳定尺寸的帧数。幅度误差尺度为 2.5%，时间尺度为 12 帧。稳定尺寸取 f1054..f1070 的中位数。
3. 抬起的可见代理：轮廓外 3..25 个缩小后像素的投影暗度，相对 f1030 的增加量。误差尺度为 0.05。俯视视频不能可靠恢复真实 z 高度，不能把投影测量称为物理高度。
4. 四角附近白点的数量、面积曲线及首次同时检出四点的帧数。面积尺度为原图 320 平方像素，时间尺度为 12 帧。光标遮住角点时可能漏检，报告实际最大检出数；没有检出时记为观察窗外，而不是补造出现帧。

各误差用指数衰减转为分数。`score.json` 同时输出参考和候选的实际峰值、帧数及各子分，不能只看总分。

## 运行回归检查

```sh
BUILDQ_MIN_FREE_GB=10 ~/.claude/bin/testq -- scripts/score/regress.sh .score-cache/本轮回归
```

四项串行。只有 `test-drag.sh` 允许失败后重跑一次。其他测试失败立刻停止，完整输出保存在指定目录。

## 保留条件与限制

每次只改一个物理参数或一小段布料逻辑。总分提高、四段 IoU 均未比上次保留版本降低超过 0.01，才进入四项回归检查。回归全部通过才提交。额外报告四段节奏，防止总分掩盖局部过程退步。连续八次不满足保留条件后停止。

输入轨迹来自逐帧人工分析，约有 10 像素误差，松手时间也有推断。此指标是固定参考下的近似比较，不是对原应用内部参数的恢复。遮罩不能判断折痕内部是否尖直、翻过去的片是否真正平躺，保留版本仍须查看并排视频和截图。

`camera.json`、`floor.png`、重放初态和轨迹复用上一轮任务素材。它们只供本地对照测试，包含的木地板图来自任务授权的参考视频，不是产品材质，未经单独授权不对外发布。没有复制 Terkel 的地毯花纹到产品。
